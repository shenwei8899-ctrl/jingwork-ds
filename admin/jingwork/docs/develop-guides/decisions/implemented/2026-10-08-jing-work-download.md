# Jing Work 下载入口与下载页

状态：implemented
类型：feature
Owner：web/src/views/DownloadView.vue

## 问题

官网顶部工作台按钮需要改为下载，并提供参考 Octop 下载页的 Jing Work 品牌页面。目标是让访客找到真实可用安装包和安装条件；不构建新版本、不将上游软件冒充为本产品、不发布未经确认的其他平台安装器。

## 决策

### 实现方案

首页桌面及手机导航的主按钮进入公开 `/download` 路由，现有工作台入口仍保留在上手指引中。页面复用首页导航、蓝鲸与青蓝配色，提供桌面安装卡、网页版入口、企业指引和版本详情。安装包元数据由 `web/src/content/downloads.js` 拥有，本地已有品牌 DMG 放入忽略版本控制的公开下载目录，由既有前端服务与生产构建交付。

`web/src/apis/download_api.js` 通过静态资源 HEAD 检查文件存在、内容类型和字节数，检查中禁用下载；缺失、HTML 回退、大小不符或网络失败显示可重试的不可用状态。检查最长等待十秒，离开页面取消请求。单元测试使用模拟响应，不依赖被忽略的二进制文件；真实包完整性由下载文件的 SHA-256 和 DMG 校验验证。

## 替代方案

直接使用 Octop 发布链接会下载其他品牌软件。新建跨平台打包流水线超出页面改造范围。现有 2026-10-04 macOS ARM64 品牌包可以下载，但明确标注开发预览、未公证且不代表后续企业集成功能。

## 后果

静态安装包需要部署者在构建前放入公开目录，未提交二进制不代表远端构建自动拥有包。页面提示签名和版本边界，不提供绕过系统安全检查的操作。安装指南同步更新下载入口与版本范围。

现有包为 209 MiB 的 macOS Apple Silicon 开发预览版，采用本地 ad-hoc 签名且未经 Apple 公证。没有 Windows、Intel Mac 或独立桌宠安装器，右侧卡片使用真实网页版入口。版本不保证包含当前企业统一账号与模型同步功能，当前企业用户继续使用管理员分发的客户端。页面不修改客户端源码、企业权限或业务 API。
