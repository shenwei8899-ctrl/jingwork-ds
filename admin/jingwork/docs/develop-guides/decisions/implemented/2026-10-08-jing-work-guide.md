# Jing Work 公开产品文档

状态：implemented
类型：feature
Owner：web/src/views/GuideView.vue

## 问题

官网的阅读文档入口指向上游工程文档，需要提供与蓝鲸品牌一致、参考 Octop 文档结构的 Jing Work 使用指南。面向产品使用者与管理员，前提是具有已部署的工作台或客户端；目标是完成入门、查阅概念、配置和排障，不创建安装包、不改变登录和业务权限。

## 决策

### 实现方案

公开 `/guide/` 路由使用现有 Vue 前端交付。`web/src/content/guide` 拥有 25 篇正文 Markdown 与四组目录；`web/src/utils/guide.js` 拥有关闭原始 HTML 的 Markdown 渲染、唯一锚点与全文搜索。页面提供搜索、正文锚点、前后页、示例复制、既有主题切换和手机导航。搜索无匹配时显示可恢复的空状态，未知章节显示文档未找到，不静默回退到首页。

蓝鲸与真实桌面截图使用本站静态资源；首页五处文档链接同页进入本站。内容按当前统一登录、中央模型管理和个人/企业数据边界编写，底层技术名称保留真实拼写。本文档替代[官网首页决定](2026-10-08-jing-work-homepage.md)中的外部文档入口，不改变业务 API、认证、资源权限或运行数据。

## 替代方案

直接链接 Octop 文档会出现错误品牌与不适用的部署步骤；新增独立文档服务会增加启动与部署依赖。公开指南随既有前端构建发布，工程文档站保持原职责与导航。

|---|---|---|---|---|---|

文档单测 6/6 通过，包含全部正文链接、图片存在性、目录一致性、搜索、重复标题、安全渲染和 Vue 模板编译。全量前端 ESLint、前端生产构建与改动文件 Prettier 检查通过。工程契约测试 63/63 通过；仓库契约检查保留 29 项既有决策格式问题。完整业务单测、后端回归和独立 Reviewer 审查为 Not run；无业务后端变化。本产品文档随前端构建，不由独立 VitePress 工程文档站构建，后者未运行。

视觉与交互结果见[验收报告](../../../../design-qa.md)、[桌面截图](../../../design-evidence/guide/jing-guide-desktop.jpg)与[手机截图](../../../design-evidence/guide/jing-guide-mobile.jpg)。

## 后果

公开指南保持参考站三栏结构，正文按实际产品边界独立改写。上游云镜像、独立 Docker 安装器、FnOS 与迁移命令没有作为 Jing Work 安装能力发布。文档无模型调用和业务数据写入，公开截图不包含客户对话。新增正文须同时维护目录和链接测试；工程独立文档站保持原职责，不增加运行依赖。
