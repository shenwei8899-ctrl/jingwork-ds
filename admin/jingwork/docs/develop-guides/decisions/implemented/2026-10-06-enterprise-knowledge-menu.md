# 企业知识库入口复用原管理页面

状态：implemented
类型：feature
Owner：web/src/views/EnterpriseKnowledgeManageView.vue

## 问题
企业菜单知识库项没有管理内容。

## 决策
在企业知识库入口嵌入原 DataBaseView，继续使用原创建流程、列表查询、卡片管理操作及详情路由。直接打开企业资源页面时展开对应菜单分组。

## 替代方案
复制管理组件与接口会产生两套实现，后续知识库能力容易不一致。

## 后果
共享原知识库数据和权限边界；详情继续进入 Yuxi 原知识库详情页。未改变文件上传、图谱、检索或评估的实现。

## 验证
真实页面验证列表和创建弹窗；运行相关前端 unit、lint 和 build。
