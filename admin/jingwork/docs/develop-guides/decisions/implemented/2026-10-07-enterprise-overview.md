# 企业组织概览

状态：implemented
类型：feature
Owner：web/src/views/EnterpriseOverviewView.vue

## 问题
组织概览导航没有对应内容，需要在首页聚合企业信息和已有资源统计。

## 决策
沿用 WorkBuddy 快速上手、汇总卡片、套件列表结构，读取 companyApi 与 dashboardApi 现有接口。管理入口导航到现有企业页面。统计来源保持服务端口径；未接入的订阅与席位明确标注，不生成模拟额度。失败显示错误与重试入口，未知数据使用破折号。

## 替代方案
直接复用数据看板会缺少组织管理入口；复制外部计费数值会误导用户。当前页面仅聚合既有只读接口，不改变权限、计费或持久化。

## 后果
统计遵循现有接口权限；当前用量为 Yuxi 系统统计，不代表独立桌面端所有本地消息或商业额度。

## 验证
针对新视图及导航运行 ESLint，Vite 构建成功。管理员真实浏览器验证组织成员、资源计数和入口导航。全量前端单元测试通过（退出码 0）。
