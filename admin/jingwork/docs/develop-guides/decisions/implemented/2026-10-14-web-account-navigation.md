# 网页账号入口与权限反馈

状态：implemented
类型：bug-fix
Owner：web/src/views/LoginView.vue

## 问题
网页登录没有注册入口，普通成员点击管理菜单被静默送回对话页，无法判断页面是否生效或如何配置模型。

## 决策
### 实现方案
公开 `/register` 复用登录页表单，调用已有 `/api/auth/register`，注册成功返回登录并填入账号；默认成员权限与事务仍由 registration_service 拥有。保留登录目标路径。权限不足跳到说明页面，提供返回对话和官网操作；普通成员导航不展示企业管理菜单，并说明模型由管理员配置。管理员继续使用已有模型供应商管理页。

## 替代方案
邀请码注册或仅管理员创建账号会改变用户指定的公开注册模式。给普通成员开放供应商管理会扩大权限，不采用。
