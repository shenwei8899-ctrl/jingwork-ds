# 企业信息与联系人资料

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/company_repository.py

## 问题
企业设置入口需要参考 WorkBuddy 企业信息卡片、编辑弹窗及联系人表格，真实保存组织资料。

## 决策
企业资料由固定配置键 enterprise_company_profile 存入已有 ConfigOption 表，首次保存生成服务端企业 UUID，后续更新保留身份。对已有记录加事务行锁；初次并发创建使用唯一键冲突处理。管理员可读，仅超级管理员修改。字段和联系人使用受控 Pydantic 校验，最多 30 位联系人。

界面包括名称、企业 ID、行业、规模、域名、邮箱后缀和联系人增删改。邮箱后缀是资料字段，不改变 SSO 配置。联系人仅保存资料，不声称具备短信或邮件通知服务。未设置字段明确展示默认状态。

## 替代方案
浏览器本地存储无法跨设备维护。复制腾讯账号域名或企业 ID 会伪造本地身份。

## 后果
使用现有表无需 schema 改动。企业 UUID 在首次保存前未生成。当前使用默认企业图标，暂不提供自定义头像上传。

## 验证
真实 PostgreSQL 验证保存与回读、更新保留企业 ID；校验错误邮箱和联系人上限；HTTP 验证未登录和普通用户无法读取。前端 lint/build 验证。
