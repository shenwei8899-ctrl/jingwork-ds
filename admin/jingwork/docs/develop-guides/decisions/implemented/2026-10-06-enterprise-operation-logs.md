# 企业操作日志查询

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/operation_log_repository.py

## 问题
企业操作日志菜单缺少内容，管理员无法浏览现有操作记录。

## 决策
复用 Yuxi OperationLog 持久事实，在管理员只读接口提供员工、真实操作类型、UTC 时间范围与 ID 游标分页。企业页面呈现列表、刷新、重置、加载更多与详情；时间展示采用浏览器时区，查询发送带时区 ISO 时间。原写入事务和日志内容继续由原业务用例拥有。

## 替代方案
连接旧企业审计服务需要另一套企业身份和专用对象 ID。复制其 Run、知识版本和授权快照字段会创造 Yuxi 中不存在的事实。通用 HTTP 中间件无法保证业务提交和审计提交处于同一事务，因此不扩大写入覆盖。

## 后果
日志可见范围仍限管理员。可查询的操作覆盖现有账号、用户和部门管理写入；智能体、模型、技能与知识库操作未在此任务补齐审计写入。无伪造状态、自动补写旧历史或对话正文采集。

## 验证
真实 HTTP 与 PostgreSQL 验证管理员、普通用户、未登录、时间范围、时区转换、游标不重复、原始详情与分页上限。前端 lint、build 与真实页面验证记录及详情。
