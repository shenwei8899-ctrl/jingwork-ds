# 竞网蓝鲸品牌官网首页

状态：implemented
类型：feature
Owner：web/src/views/HomeView.vue

## 问题

公开首页需要以 Octop 首页为布局参考，展示竞网蓝鲸品牌、用户提供的蓝鲸吉祥物，以及运行中的 Jing Work 产品界面。

## 决策

### 实现方案

在现有 Vue 公开首页内实现导航、首屏、上手指引、桌面伙伴、功能切换、常见问题和行动入口。使用页面局部青蓝渐变变量及已有图标库；蓝鲸图片和客户端实际截图随前端静态资源发布。继续使用现有健康检查、错误重试和登录路由。产品介绍和功能切换只修改页面状态，不调用模型或改变业务数据。

## 替代方案

独立创建静态站会造成现有根路由与预览地址分离；整站复制 Octop 的品牌、下载和安装命令会指向不同产品。选择复用当前首页入口、按本产品能力改写内容和入口。

## 后果

截图只选取无客户业务内容的产品页面。品牌样式限制在公开首页；服务端权限与业务流程不变。客户端截图是展示素材，不代表网页提供桌面专属能力。文档入口由[Jing Work 公开产品文档](2026-10-08-jing-work-guide.md)接管，指向本站指南。
