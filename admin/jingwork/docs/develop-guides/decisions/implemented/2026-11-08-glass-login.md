# 登录页使用共享玻璃卡片设计

## 问题

桌面客户端展示的 Yuxi 登录页与竞网蓝鲸现有 Octop 登录页不同，品牌与表单布局不一致。

## 决定

登录页复用 Octop 的背景、420px 居中卡片和品牌布局，保留 Yuxi 登录 API、初始化、注册、协议与授权跳转。前端滑块通过后允许密码提交，失败后重新验证。滑块支持指针与键盘操作，服务端继续校验凭据和锁定策略。

记住登录状态默认开启。关闭时，浏览器令牌写入 sessionStorage；开启时写入 localStorage。既有调用默认继续持久登录，退出同时清除两处令牌。忘记密码提供联系管理员重置的说明。

注册使用紧凑品牌行和三个必填字段，精简说明文字与间距，协议和操作保留在卡片内。1040×640 的窗口中，默认和校验错误状态均完整展示。

## 验证

相关单元测试覆盖滑块未完成与完成、重复验证、两种令牌存储及退出清理。浏览器验证桌面、390px 窄屏和实际拖动，构建与相关文件 lint 通过。
