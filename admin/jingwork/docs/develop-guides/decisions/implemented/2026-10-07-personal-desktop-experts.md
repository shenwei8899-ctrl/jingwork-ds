# 专家管理按统一账号读取桌面目录

状态：implemented
类型：feature
Owner：backend/server/routers/octop_expert_router.py

## 问题
企业专家管理需要展示当前用户桌面端的个人专家与团队，以及公共模板目录。

## 决策
个人目录由当前中央登录会话访问通过 `YUXI_DESKTOP_URL` 显式配置的固定桌面服务。未配置时返回 `available=false` 与接入提示，页面显示目录尚未接入，不推测服务器宿主端口上的应用是桌面服务。桌面服务向配置的统一身份源验证会话，从 UID 与 SSO subject 映射本地账号，不接受调用方指定其他 UID。专家按账号归属读取，团队使用原有 list_for_user 投影。未关联用户返回明确未关联状态；连接故障返回错误。

## 替代方案
按用户名匹配无法区分重名及改名。管理员选择任意用户不符合“我的专家”语义。

## 后果
个人目录当前为只读展示，刷新读取桌面最新配置，桌面服务需要显式接入并在线；云服务器上的宿主端口不能代表用户电脑上的桌面端。模板继续复用已有目录与导入组件。中央权限与桌面身份验证均保留。

## 验证
真实 SQLite/HTTP 集成测试验证关联用户可读、自身之外未关联用户为空。真实页面验证个人专家、团队、内置专家与市场标签。前端 lint/build 与相关 Ruff 校验通过。
