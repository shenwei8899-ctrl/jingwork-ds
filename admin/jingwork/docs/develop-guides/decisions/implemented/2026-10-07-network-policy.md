# 企业桌面网络白名单

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/network_repository.py

## 问题
企业网络设置需要持久保存 IP 白名单并实际限制统一账号桌面业务访问。

## 决策
固定配置键保存在现有 ConfigOption 表。超级管理员修改；统一登录用户可读取策略供桌面服务执行。受控输入支持 IPv4/IPv6/CIDR，规范化及去重，最多 200 项。空白放行；仅 127.0.0.1/32 禁止统一账号桌面业务访问，与参考规则一致。

桌面 HTTP 在本地认证后读取中央策略；WebSocket 在原认证流程读取策略，使用 ASGI 上下文传递实际连接来源，覆盖查询参数及首帧认证。策略读取失败拒绝访问。仅对已关联统一登录的用户生效；本地账号及后台管理入口不受限制。

## 替代方案
仅保存前端配置不能限制访问。信任任意 X-Forwarded-For 会允许客户端伪造地址，因此使用连接来源。

## 后果
反向代理连接采用代理实际地址，暂不支持可信代理 CIDR 配置；本机客户端连接采用 loopback 地址。HTTP 每次请求读取策略，现有 WebSocket 不主动断开，重新连接或认证时应用新策略。登录入口本身不拦截，但受保护业务接口与 WebSocket 身份认证执行限制。后台显示的是后台连接地址，不声称是公网客户端 IP。

## 验证
真实 PostgreSQL 验证规范化、去重、保存回读、留空更新和权限拒绝。桌面真实 HTTP/SQLite 测试验证留空放行及禁止访问，WebSocket 认证验证拒绝逻辑；单元测试覆盖 IPv4、IPv6及映射地址。前端 lint/build 验证。
