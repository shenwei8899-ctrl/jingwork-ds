# 桌面工具按账号授权

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/desktop_tool_service.py

## 问题
桌面个性化工具只有本地智能体开关，后台无法控制员工可用工具。

## 决策
AI 资源管理增加工具管理。管理员按 uid 保存工具禁止列表，PostgreSQL ConfigOption 拥有配置事实。桌面保留本地开关，每次实际调用实时检查认证账号的后台授权；无法确认身份或无法连接后台时不执行工具。插件目录只登记当前用户的工具描述，不允许修改授权。

## 替代方案
仅同步界面开关无法防止旧页面或直接请求执行。全企业统一策略不能满足用户要求的逐账号授权。

## 后果
默认保留既有内置工具能力，管理员可逐项撤销。新登记的插件工具默认禁止，需要管理员授权；未登记插件工具无法直接执行。授权不覆盖工具审批机制。工具调用依赖后台可用性，并增加一次授权读取。

## 验证
真实 HTTP 和 PostgreSQL 覆盖管理员写入、普通用户禁止写入、跨账号读取隔离、版本冲突和插件登记不扩大授权。桌面执行拦截测试覆盖撤销、实际 actor 与后台断线。真实页面已验证新菜单、成员选择与中文工具目录。后台 HTTP/PG 测试 1 项通过，桌面授权和工具设置测试 8 项通过。前端构建与目标源码 lint 通过；全仓工程检查仍有此前记录格式错误。
