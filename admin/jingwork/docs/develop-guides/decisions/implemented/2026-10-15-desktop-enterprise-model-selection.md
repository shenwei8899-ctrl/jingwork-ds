# 普通桌面助理选择企业模型

自有供应商的桌面调用路径和凭据边界由[桌面直连公司自有模型](2026-10-28-desktop-direct-model.md)部分取代；下文网关决定保留适用于中转和 UID 签名模型。

目标：所有可访问的桌面助理均可列出个人与企业模型，并实际调用所选模型。

决定：桌面普通 Harness 保持本地工具、技能、审批与历史；企业模型引用经当前账号会话发送到企业 OpenAI 兼容网关。后台不发送供应商密钥。企业助理原有远程 Agent Call 保持现有路径。

后台显式模型选择必须通过当前账号 allowed_models 校验，reserve_call 按实际所选模型及对应价格预占和结算；不允许静默改用默认模型。managed=false 的账号仍使用当前既有模型调用策略。未指定模型的旧客户端继续使用后台默认模型。

替代项：把企业供应商密钥传给桌面，破坏密钥边界；将普通助理迁移至企业 Agent Run，丢失本地工具/技能行为。均不采用。

验收：普通/共享助理列表、个人模型保持本地、企业模型经认证网关、选中模型保持一致、未授权模型不产生供应商调用、真实桌面短消息两种来源均成功。影响范围为模型解析器、网关入口与额度预占；不涉及 schema。
