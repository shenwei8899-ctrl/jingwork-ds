# 明细数据按成员与部门统计桌面素材

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/statistics_detail_repository.py

## 问题
企业明细页面需要参考 WorkBuddy 的成员/部门、时间、筛选和导出布局，并展示可验证的数据。

## 决策
使用中央已同步 DesktopConversationEvent 按成员统计会话、消息、用户消息、AI 回复和使用专家数。会话按设备、专家、thread 去重。部门按成员汇总消息和会话，不用专家数相加伪装为部门独立专家数。所有用户包含零活动账号，身份和部门名称来自当前中央资料。

日期按北京时间转换为 UTC 半开窗口，结束日期包含完整一天，限制一年查询窗口。仅超级管理员访问，与原数据看板权限一致。页面以成员和部门切换、快捷日期、自定义日期、部门选择、成员搜索、分页及 CSV 导出构成。

## 替代方案
复制第三方代码补全统计列并填 0 会把未采集误作真实零使用；未采集指标明确标注。不抓取第三方公司成员数据填充本地。

## 后果
数据仅覆盖桌面已捕获且已同步素材，统计会话数并非完成大模型调用次数。尚无插件版本、客户端遥测和代码采纳指标。CSV 导出当前筛选全部结果并处理公式起始字符。

## 验证
真实 HTTP/PostgreSQL 测试覆盖管理员权限、时间边界、成员和部门汇总、合法请求及反向日期拒绝。前端 lint/build 校验。
