# 企业模型管理复用供应商面板

面向企业后台维护者。目标是在 `/enterprise?page=models` 提供原 `/agent-manage?tab=providers` 的模型供应商功能。

## 决策

`EnterpriseModelManageView` 直接挂载 `ModelProviderManagePanel`，保留搜索、新增供应商、供应商配置与模型管理等原生交互。两处共享已有 API、数据和服务端授权，不复制配置状态，也不新增供应商接口。

企业页面沿用原入口的管理员可见条件；普通用户显示无权访问。原入口保留。此次不修改模型调用、凭证存储或桌面端配置协议。

## 验证

真实页面加载已有供应商，并成功打开模型配置弹窗，显示已启用模型、手动添加、远程模型和连接测试入口；验证过程中未修改供应商或凭证。前端 lint 和生产构建通过，完整 unit 执行结果记录在交付报告中。
