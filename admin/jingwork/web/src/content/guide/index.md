# Jing Work：你的智能工作伙伴

懂你、帮你，陪你成长的智能伙伴。

Jing Work 将对话、专家、知识库和工具连接在一个工作空间里。你可以在桌面客户端处理日常任务，也可以通过企业工作台使用团队提供的智能体。蓝鲸陪你整理资料、构思内容、分析问题，让想法一步步落地。

![Jing Work 真实聊天界面](/home/jing-chat.jpg)

## 你可以用 Jing Work 做什么

- **与专业专家协作**：按任务选择专家，让角色说明、模型和技能共同参与工作。
- **用自己的资料辅助回答**：连接已授权的知识库，核对检索依据与引用。
- **连接日常工具**：通过连接器与 MCP 使用外部服务，按需授予访问权限。
- **安排重复工作**：在自动化中设置执行计划，查看运行结果与失败原因。
- **与编程助手配合**：在支持的环境中通过 ACP 连接编程智能体。
- **团队协同管理**：由企业后台管理组织、模型、共享智能体及访问权限。

## 个人与企业的边界

桌面个人工作空间与企业资源具有不同的数据归属。企业智能体、中央账号和模型受企业后台管理；个人资料与桌面配置依部署方式保存。使用外部模型、连接器或消息平台时，相关内容会发送给对应服务，不能把“本地客户端”理解为“所有数据永不离开本机”。

本文档面向当前 Jing Work 桌面与企业集成版本。入口是否可见取决于账号权限、管理员配置和已安装的可选组件。
