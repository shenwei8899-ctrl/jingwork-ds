# 安装与登录

Jing Work 桌面客户端与企业工作台配合使用。本页面向已获得组织使用授权的用户。

## 获取与打开客户端

从[下载页](/download)选择与你的操作系统和芯片架构匹配的使用方式，或从组织管理员提供的可信分发位置获取客户端。当前下载页提供 2026-10-04 的 macOS Apple Silicon 品牌预览包 v1.0.2b5，要求 macOS 13.0 及以上。它使用本地签名、未经 Apple 公证，早于后续企业统一账号与模型同步改造，不保证具备当前运行版本的全部功能。

完成安装后打开 Jing Work。已有安装的用户直接启动客户端即可。系统阻止未知来源应用时，先核验分发来源、签名和版本，并交由管理员处理，不要关闭系统安全防护来绕过检查。

## 使用统一账号登录

启用企业统一登录的客户端使用与工作台相同的账号 ID / 手机号和密码。登录成功后，桌面读取该账号有权访问的企业资源。角色与可见性由服务端校验，改写客户端名称不会授予权限。

同名历史本地账号不会自动与企业身份合并。旧账号资料需要另行评估迁移，不能通过重复注册找回。

## 首次使用检查

1. 确认可以进入聊天页面并看到可用专家。
2. 在模型选择中确认有可用模型；为空时让管理员检查中央模型配置。
3. 发送一条不含敏感资料的测试消息，核对实际回复。
4. 根据需要再授权文件、连接器和工具。

## 登录失败怎么办

先在企业工作台验证账号是否可用，再检查客户端网络与企业服务地址。会话过期时重新登录；忘记密码或账号停用时按[账号与密码](/guide/guides/reset-password)处理。
