# 自动化任务

自动化让专家按计划执行重复任务，例如整理日报或检查指定资料。创建计划与执行成功是两个独立结果。

## 建立计划

打开“自动化”，选择专家，填写清楚的任务目标与执行时间。任务应能在没有临时补充信息的情况下完成；使用外部资源前确认相关授权仍有效。

## 时间与时区

执行时间以服务配置的时区为准，不应仅凭电脑时钟推断。创建后核对页面显示的下一次执行时间，特别注意跨时区、夏令时和重复规则。

## 核对运行结果

保存后检查任务是否启用，观察运行记录、输出和错误。先使用简单的只读任务验证，再扩大到正式工作。失败时检查专家、模型、资源授权和服务可用性。

## 暂停与维护

不再需要的计划应在自动化页面停用。调整任务之前查看是否已有运行中的执行；不要假设修改计划会撤销已经发生的外部操作。
