# 备份与恢复

Jing Work 涉及桌面数据和企业服务数据。备份需要覆盖真实持久化位置、配置与密钥，不能只复制客户端应用包。

## 确认备份范围

- 桌面运行时：实际数据根目录、配置、工作区、数据库与解密所需密钥。
- 企业服务：PostgreSQL、对象存储和知识服务持久数据，以及部署配置与密钥。
- 外部连接器：服务方的数据不一定属于本地备份范围，需要独立确认。

具体归属见[数据目录](/guide/configuration/data-directory)。

## 制作一致副本

由管理员按照实际数据库和存储类型执行一致性备份。需要停写的方案必须先停止全部写入者；运行中的数据库不能仅凭文件复制保证一致性。

备份包含敏感信息，存放到有访问控制的私有位置。记录版本、范围、时间和校验结果，不把备份上传到公开共享链接。

## 恢复演练

先恢复到隔离的新环境，核对登录、文件、知识检索及密钥解密。确认兼容性和完整性后再制定正式切换方案，保留原数据与回退路径。

上游独立 SQLite 企业备份工具不覆盖当前 Yuxi 的 PostgreSQL 与对象存储部署，不可直接套用。

## 定期验证

只有备份文件存在不能证明可恢复。定期演练，并检查新增存储、外部对象和凭据变更是否仍在保护范围内。
