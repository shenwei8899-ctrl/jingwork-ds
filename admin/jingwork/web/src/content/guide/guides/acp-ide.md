# ACP 与编程助手

ACP 用于与支持该协议的编程智能体协作。可用 Runner 和接入方式取决于当前安装版本及外部工具。

## 准备环境

在管理员允许的环境安装受信任的编程工具，完成其自己的登录或模型配置。确认运行账户能访问指定项目，并理解外部工具可能调用的网络服务。

## 建立连接

打开“ACP”入口，按界面选择或配置可用 Runner，指定项目目录。先验证连接，再发送范围明确的小任务，例如只读解释某个模块。

## 保护项目

开始修改前检查版本控制状态并保留已有工作。描述允许修改的文件、验证方式和禁止操作；涉及安装依赖、提交代码或发布时单独核对授权。

## 排查问题

Runner 不可用时检查命令是否安装、执行环境与认证是否有效。目录权限或协议不兼容时应修复对应环境，不要扩大系统权限掩盖故障。
