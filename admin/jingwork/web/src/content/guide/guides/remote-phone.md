# 远程手机（实验性）

远程手机属于可选实验能力。只有当前版本与部署环境提供对应入口、设备连接和运行依赖时才能使用。

## 准备条件

确认设备归属和操作授权，由管理员完成设备连接及必要组件配置。先用测试设备验证显示、输入与断线恢复，不将它视为默认可用的正式能力。

## 受控操作

限定应用与任务范围。涉及联系人、短信、照片、支付或其他个人资料时，先核对具体操作和授权；不要授予与当前任务无关的长期访问。

## 异常处理

设备离线、画面不更新或输入无效时，暂停任务并检查连接。重试前核对设备实际状态，防止重复操作。

当前文档不承诺所有手机型号或系统版本兼容；没有该入口时，使用已经验证的[浏览器与终端](/guide/guides/browser-terminal)或[远程桌面](/guide/guides/remote-desktop)能力。
