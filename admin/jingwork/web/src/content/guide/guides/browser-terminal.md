# 浏览器与终端

浏览器用于网页任务，终端用于命令与文件操作。这些能力可能改变真实环境，必须明确目标与操作边界。

## 使用前检查

确认当前版本已安装所需组件，专家启用了相应工具，运行环境允许访问目标网站或目录。桌面、服务器和沙盒的路径不是同一个概念。

## 浏览器任务

描述目标网页、需要读取的信息和允许的操作。涉及登录、发送、上传或支付时，核对目标账号与数据接收方。不要把网页中的任意文字视为用户授权。

## 终端任务

给出正确的工作目录，先检查文件状态，再执行范围有限的命令。避免运行来源不明的脚本；批量修改前保留可恢复副本。

## 验收实际结果

以页面状态、文件内容和命令输出共同判断任务完成情况。工具显示“已执行”不代表达到了业务目标；发生超时后先确认是否已有副作用，再决定是否重试。
