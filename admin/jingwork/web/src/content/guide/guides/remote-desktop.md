# 远程桌面

远程桌面让你查看并操作已授权的远程环境。该能力依赖当前版本、远程端服务和网络配置。

## 准备连接

由管理员提供可信连接信息，确认操作系统会话、显示服务与网络可达。只连接你有权控制的设备，不在普通聊天中暴露连接凭据。

## 进行任务

进入“远程桌面”，先确认画面对应正确设备与账号，再让专家执行明确的操作。保持任务范围有限，涉及外部提交或文件覆盖时核对对象。

## 断线处理

连接断开时先查看远程任务是否仍在运行。重连后核对实际页面与文件状态，避免重复提交。

## 使用限制

远程桌面可用不意味着远程文件可直接通过本地路径读取。传输资料时确认来源、目的地和权限，结束后关闭不再需要的会话。
