# 账号与密码

当前统一登录版本以企业账号为身份来源。桌面与工作台使用同一账号，资源权限由服务端验证。

## 忘记密码

联系组织管理员按中央账号管理流程处理。不要执行上游本地管理员重置命令来修改企业身份，也不要通过新建同名本地用户尝试找回企业资料。

## 会话过期

重新登录以获取有效会话。页面反复跳转时，先确认企业服务可达和账号正常。退出登录会清除当前中央会话，后续访问需重新认证。

## 角色与资源变化

管理员角色和普通成员权限以中央身份为准。账号停用、角色降级或资源撤权后，相关操作会被拒绝。列表中残留的旧信息不构成访问授权。

## 安全建议

使用唯一密码，不共享账号或 Token。不在工单截图、日志附件或聊天中暴露密码。遇到无法解释的登录行为时，及时联系管理员核对账号与审计记录。
