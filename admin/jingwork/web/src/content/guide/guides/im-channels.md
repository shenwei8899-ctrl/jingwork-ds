# IM 通道

本指南用于把已支持的消息平台接入 Jing Work。平台种类和字段以当前通道页面提供的选项为准。

## 准备平台应用

由有权限的管理员创建平台应用或机器人，设置必要权限、事件订阅和回调地址。涉及组织审批时先完成审批；服务部署还需满足平台的网络和 TLS 要求。

## 配置通道

在“通道”中新建目标类型，填入平台配置并选择接收消息的专家。凭据只放在专用配置位置。先把测试范围限制为少量授权成员。

## 验证收发

从平台发送一条无敏感内容的消息，确认专家能收到并回复到正确会话。检查事件是否重复、回调是否超时，以及附件与群聊消息是否按预期处理。

## 排查异常

收不到消息时检查平台事件权限、通道状态和回调可达性；收到但不能回复时检查平台发送权限和模型状态。不要用生产群组反复测试有副作用的工具。
