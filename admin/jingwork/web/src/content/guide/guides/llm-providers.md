# 模型管理

模型决定专家的推理能力。当前统一集成版本的聊天模型由企业后台管理，桌面端读取同步后的可用配置。

## 管理员配置

在[企业工作台](/enterprise?page=models)打开模型管理，选择供应商，配置正确的服务地址、API Key 与模型名称。启用需要的模型后进行连接测试。

不要把 API Key 粘贴进专家角色说明或普通聊天。配置地址时核对供应商协议与网络可达性。

## 桌面同步

桌面“管理 → 模型”中的中央聊天模型为只读投影。管理端变更后，可等待同步或刷新列表。不要在桌面重复创建同名配置来绕过中央管理。

图像、语音等其他模型能力依当前版本和单独配置而定，不能从聊天模型可用推断它们也已就绪。

## 在任务中选择

选择与任务类型匹配的模型，核对是否支持所需输入和工具调用。大文件、复杂任务与长对话受模型上下文和服务配额限制。

## 连接失败

检查密钥有效性、请求地址、模型标识、账户余额和网络策略。管理页面显示模型只证明配置存在，实际响应成功才证明该次调用可用。
