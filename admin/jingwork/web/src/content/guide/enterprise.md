# 企业工作台

企业工作台集中管理团队资源。管理员从官网进入[企业控制台](/enterprise)，普通成员通过[工作台](/agent)使用已授权能力。

## 管理员准备顺序

1. 核对组织与成员信息，分配符合职责的账号权限。
2. 在模型管理中配置供应商、密钥和启用模型。
3. 创建或配置企业智能体，明确角色、知识、技能及工具。
4. 设置共享范围，用普通成员账号验证资源可见性和实际调用。
5. 查看操作日志与用量，持续核对配置变更和执行情况。

## 个人与共享资源

个人资源与企业共享资源的管理入口不同。一个资源出现在管理员列表中，不代表所有成员都能使用。后端按当前账号和资源规则执行权限校验。

桌面端展示企业专家并不复制企业管理员权限；会话过期、资源取消共享或账号被停用后，调用会被拒绝。

## 部署范围

当前企业工作台基于 Yuxi 服务运行，包含 API、worker、PostgreSQL、Redis、对象存储和知识服务等组件。上游 Octop 的单容器快速安装不能替代这套部署。

管理员应使用本项目随版本维护的部署配置，确认存储迁移、服务就绪和 worker 可用。产品文档不提供未经验证的云镜像、默认密码或一键生产部署承诺。

## 使用前验收

能打开网页只说明前端可访问。正式使用前还需验证登录、模型回复、知识检索、附件读取和工具授权；涉及写入的测试先使用可丢弃的测试资料。
