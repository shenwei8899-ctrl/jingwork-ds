# 快速开始

本指南带你从登录到完成第一项任务。开始前，请确认已有可用账号、管理员提供的工作台地址或已安装的 Jing Work 客户端，以及至少一个可用模型。

## 1. 进入你的工作空间

在官网点击[进入工作台](/agent)，或打开桌面的 Jing Work。使用管理员分配的账号 ID / 手机号与密码登录。启用统一账号的版本使用企业账号；不需要再填写第二套企业 API Key。

如果未安装客户端，先阅读[安装与登录](/guide/desktop)。服务离线或账号被停用时，先联系管理员处理，不要反复创建新账号。

## 2. 选择一个专家

打开“专家”，查看内置专家或你有权限使用的企业智能体。根据任务选择助手，再进入对话。企业专家未显示时，请管理员检查共享范围与账号状态。

![Jing Work 专家列表](/home/jing-experts.jpg)

## 3. 描述目标与交付要求

给出目标、背景、可使用的材料和期望格式。先从不涉及敏感资料的小任务开始，例如：

```text
请帮我整理一份项目周报提纲。
包含：本周进展、遇到的问题、下周计划。
每部分列出三个要点，不要编造尚未提供的项目数据。
```

需要处理文件时，选择正确的附件或工作目录。涉及外部服务或工具操作时，核对执行对象、权限和可能产生的变化，再确认授权。

## 4. 核对结果并继续

阅读回复、引用与产物，确认任务是否达到要求。可以在同一对话里补充约束；切换主题时开启新对话。工具报错或模型不可用时，先查看具体错误，再按[常见问题](/guide/guides/faq)排查。

下一步：了解[核心概念](/guide/concepts/overview)，或为你的专家添加[技能包](/guide/concepts/skills)。
