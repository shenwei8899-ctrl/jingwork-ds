# 专家与人格

专家决定工作职责与能力组合，人格影响表达风格。两者可以一起使用，但解决的是不同问题。

## 区分职责与风格

“研究助手”需要可靠来源和清晰引用，这是职责；“表达简洁、先给结论”属于风格。将业务要求写入角色说明，把语气偏好放在表达要求中，更容易验证结果。

## 编写角色说明

```text
职责：整理用户提供的产品研究资料。
工作方式：先确认问题，再比较证据。
输出：结论、依据、待确认事项。
边界：缺少资料时标明未知，不编造引用。
风格：简洁、清楚，面向非技术读者。
```

## 使用人格模板

版本提供人格模板时，可以先选模板再调整。人格标签不保证推理质量、专业资质或数据权限；评估重点仍是实际结果。企业智能体的共享与调用边界保持不变。

## 持续调整

选择同一组代表性任务比较修改前后的结果。角色说明互相冲突时先消除冲突，不要靠叠加更多指令弥补。相关内容见[专家](/guide/concepts/agents)。
