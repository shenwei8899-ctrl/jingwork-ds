# 专家

专家把角色、模型、技能与工具组合起来，服务于一类工作任务。你可以从内置专家开始，也可以使用企业向你开放的智能体。

![Jing Work 专家页面](/home/jing-experts.jpg)

## 选择专家

打开侧栏“专家”，按任务阅读介绍。写作、分析和资料整理适合不同的角色说明；先选择最贴近当前目标的专家，再补充要求。

## 配置工作方式

有编辑权限时，明确专家名称、角色说明、模型、技能和所需工具。描述应包括职责、输出格式及禁止执行的操作。给专家添加工具前，检查其访问范围，避免为了一个小任务开放整个账户。

## 企业专家

企业专家由中央后台管理。桌面列表按当前统一账号读取授权资源，成员只能使用对自己可见的智能体。缺少资源或调用被拒绝时，联系管理员检查共享设置，不要复制其他成员凭据。

## 验证配置

使用一条固定的小任务检查回复风格、知识引用与工具调用。修改模型或技能后再次验证。效果不符合预期时，把任务目标、输入材料和期望输出补充清楚。
