# 技能包

技能包把一类任务的说明、资源与可复用流程组织起来，帮助专家按照明确步骤完成工作。

![Jing Work 技能包页面](/home/jing-skills.jpg)

## 选择技能

打开“技能包”，查看已安装技能和可用目录。先阅读用途、要求及包含的文件，确认与你的任务匹配，再安装或启用。

## 应用到专家

在专家配置中选择需要的技能。技能描述影响模型如何处理任务；实际工具、模型和文件访问仍受当前账号与环境约束。

## 安全使用

技能可能包含脚本或外部依赖。安装前检查来源与行为，尤其是网络上传、批量修改和命令执行。安装成功不代表脚本已通过安全审查。

## 验证与维护

先使用测试材料运行技能，核对产物是否符合要求。升级技能后重新检查行为；企业共享技能由管理员维护，个人安装范围与共享范围需分清。
