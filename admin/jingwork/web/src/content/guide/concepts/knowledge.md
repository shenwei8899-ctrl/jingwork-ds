# 知识库

知识库把授权资料整理为可检索内容，供专家在回答时引用。检索结果辅助判断，原始文件仍是核对依据。

## 准备资料

只上传你有权使用的文件。优先提供结构清晰、版本明确的文档，移除不必要的个人信息和凭据。不同密级的资料按访问范围分别管理。

## 建立可用知识

1. 在有权限的知识库入口创建或选择知识库。
2. 添加文件，等待解析与索引完成。
3. 为专家选择可访问的知识或相应检索能力。
4. 提出一个答案明确存在于文档中的问题，核对引用内容。

上传成功不代表索引完成。解析失败、空内容或缺少权限时，先解决对应问题再测试。

## 个人与企业知识

个人知识与企业共享知识的归属不同。企业知识由后台控制可见范围；不能因为文件曾在某次对话中出现，就假设其他成员有权访问。

## 提升回答可靠性

问题中说明资料范围与时间。对于合同、财务或其他重要结论，回到原文核对；检索没有找到依据时，请专家明确说明缺少证据。
