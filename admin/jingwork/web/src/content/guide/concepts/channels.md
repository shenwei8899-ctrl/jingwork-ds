# 通道

通道把消息平台上的会话连接到专家。它决定消息从哪里进入，以及回复送往哪里。

## 通道与连接器的区别

通道是消息入口，例如团队消息平台里的机器人。连接器是任务中可调用的工具，例如检索某个服务的文件。接入通道不会自动授予所有连接器权限。

## 接入前准备

确认当前版本已安装目标平台支持，准备平台要求的应用身份、回调配置和访问范围。消息平台的审批、订阅事件与网络要求仍然适用。

## 路由与安全

选择接收消息的专家，并核对群聊、私聊、成员和资源权限。先用测试会话验证，避免把企业资料发送到不应接收的群组。

具体步骤见[IM 通道](/guide/guides/im-channels)。
