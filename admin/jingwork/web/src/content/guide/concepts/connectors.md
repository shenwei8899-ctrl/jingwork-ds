# 连接器

连接器让专家调用外部应用或服务。Jing Work 提供内置连接器入口，也支持按当前版本能力配置 MCP 服务。

![Jing Work 连接器页面](/home/jing-connectors.jpg)

## 选择并连接

打开“连接器”，阅读服务说明。需要登录授权的服务由你确认账号与权限；使用地址或密钥的服务应由管理员提供可信配置。

“可添加”与“已连接”是不同状态。完成配置后先执行只读的小操作，确认连接成功。

## 给专家使用

为相应专家启用需要的连接器或工具。只开放任务所需能力，特别注意文件写入、发送消息、删除记录和外部请求等副作用。

## MCP 服务

自定义 MCP 服务的命令、参数、URL 和凭据必须来自可信来源。不要复制陌生网页里的启动命令直接执行。传输方式、认证方式与工具列表以服务端实际支持为准。

## 连接失败排查

检查服务是否启动、地址是否可达、授权是否过期、请求是否被网络策略阻止。更新凭据后重新测试；不把密钥写入普通对话、截图或公开文档。
