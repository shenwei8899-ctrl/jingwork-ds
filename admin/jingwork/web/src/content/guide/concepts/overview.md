# 核心概念

理解下面的概念，可以更快找到入口，也能避免把“已配置”误认为“已授权、可执行”。

## 工作空间与对话

工作空间承载你的任务与资源，对话保存某个目标下的交流。专家是执行任务的助手；模型提供推理能力，工具提供具体操作能力。

| 概念 | 解决的问题 | 入口 |
| --- | --- | --- |
| 专家 | 谁来做、以什么角色做 | 专家 |
| 模型 | 使用哪种推理能力 | 管理 → 模型 |
| 知识库 | 回答可以参考哪些资料 | 知识库 |
| 技能包 | 按什么说明和流程完成任务 | 技能包 |
| 连接器 | 可以调用哪些外部工具 | 连接器 |
| 通道 | 从哪个消息平台接收任务 | 通道 |
| 自动化 | 在什么时间执行任务 | 自动化 |

## 一次任务如何完成

选择专家，提供目标与材料，模型判断下一步，必要时调用授权工具或检索知识，最后返回结果。工具调用失败与模型回复完成是不同状态，验收时应核对实际产物。

## 配置与权限

专家说明和人格影响行为，但不会替代资源权限。连接器存在不代表已连接，模型启用不代表密钥有效，定时任务创建成功也不代表每次执行成功。以实际连接状态、运行记录与结果为准。
