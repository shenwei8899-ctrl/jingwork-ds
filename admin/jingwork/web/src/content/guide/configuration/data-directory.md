# 数据目录

应用安装位置与工作数据位置不同。删除或替换应用包不能替代数据备份，也不应被当作清理账号资料的方法。

## 桌面数据

底层运行时默认使用用户目录下的 `~/.octop/`，可通过 `OCTOP_HOME` 指定其他目录。现有 Jing Work 集成保留该技术路径。

常见内容包括 `config.json`、工作区、日志、插件、凭据相关文件以及数据库配置。数据库可能位于本地或外部服务；以实际配置为准，不假定一定有可直接复制的 SQLite 文件。

## 企业数据

企业工作台的业务与运行事实保存在 PostgreSQL；文件和原始知识对象还涉及对象存储，检索与图谱有各自持久数据。Redis 用于投递和短期事件，不替代 PostgreSQL 作为业务事实来源。

## 工作区与文件路径

本机路径、沙盒路径、对象 URL 和远程设备路径不能互换。为专家选择目录时确认它实际运行在哪个环境，并限制到当前任务需要的范围。

## 移动与清理

迁移数据前先停止相应写入、完成一致性备份并验证恢复。不要手工清除密钥目录来修复登录问题，这会影响已加密资料的读取。相关步骤见[备份与恢复](/guide/guides/backup-restore)。
