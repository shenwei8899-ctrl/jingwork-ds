# TLS 与服务

本页面向部署管理员，说明团队访问需要满足的连接和运行条件。

## 可信 HTTPS

跨设备或公网访问时使用可信 HTTPS 入口，配置正确域名与有效证书。反向代理需支持业务使用的长连接与流式响应。证书错误时修复证书链、域名或时间，不要求用户忽略安全警告。

## 服务可用性

前端、API、worker 与持久化服务各有独立职责。检查服务就绪后，再用真实登录、对话与知识任务验证完整路径。

只监听本机的桌面服务不等同于企业公网服务。开放监听地址、防火墙或外网访问前，应评估认证、访问控制和数据暴露面。

## 生命周期管理

使用组织选定的进程管理或容器编排方式维护重启与日志。升级前完成一致性备份，核对迁移要求；不要在运行中直接替换数据库文件。

## 日志与排障

收集最小必要日志并脱敏，按时间关联前端请求与服务执行结果。配置变化后同时检查新连接和已有长连接。
