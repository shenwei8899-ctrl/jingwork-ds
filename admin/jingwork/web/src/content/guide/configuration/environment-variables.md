# 环境变量

本页列出当前集成中需要区分的常见变量。名称保留底层运行时拼写，不存在自动对应的 `JING_*` 别名。

## 常用变量

| 变量 | 读取方 | 作用 |
| --- | --- | --- |
| `OCTOP_HOME` | 桌面与底层运行时 | 指定实际数据根目录 |
| `OCTOP_YUXI_URL` | 企业统一账号集成 | 指定可信的中央服务地址 |
| `OCTOP_DEFAULT_TIMEZONE` | 底层运行时 | 覆盖服务默认时区 |
| `OCTOP_ENABLE_API_DOCS` | 底层运行时 | 控制接口文档是否启用 |

## 生效与覆盖

进程启动时读取相关环境变量。修改系统服务或容器环境后，需要按部署方式重启相应服务，再检查实际生效值。不要仅修改当前终端却假设后台服务同步变化。

`OCTOP_HOME` 改变后会指向另一套数据位置，不会自动迁移旧目录。修改前先确认运行方式和备份范围。

## 凭据保护

密钥通过专用配置和部署秘密管理方式提供。不要把真实值放进命令历史、版本库、普通聊天或公共截图。

## 连接安全

中央服务地址由管理员维护；远程统一账号服务要求可信 HTTPS。配置错误时修复地址与证书，不关闭证书验证来继续登录。
