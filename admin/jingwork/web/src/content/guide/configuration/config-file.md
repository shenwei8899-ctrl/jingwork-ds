# 配置文件

配置分为桌面运行时配置、企业业务配置和专家配置。修改前先确定哪个系统拥有该项设置。

## 桌面运行时

底层运行时沿用 `config.json` 和 `OCTOP_*` 技术名称，位于实际数据根目录中。界面品牌改为 Jing Work 不会自动重命名这些路径与变量。

进程级设置包含监听地址、端口、时区、数据库和 TLS 等。修改前备份有效配置，使用当前版本支持的字段；需要重启的设置在服务重新启动后生效。

## 企业业务配置

统一账号、组织权限、中央聊天模型与共享智能体由企业后台管理。桌面修改本地文件不能代替服务端授权或中央配置。

## 专家配置

角色说明、技能和工具选择在专家配置入口维护。配置完成后，用代表性任务检查结果；不要把供应商密钥直接写入角色说明。

## 排查配置冲突

检查实际加载的数据目录及环境变量覆盖。字段拼写、值类型或版本不兼容都可能导致启动失败。恢复已验证副本后重新核对服务状态。
