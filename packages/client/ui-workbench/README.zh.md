# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

## 概述

通过 Web 或桌面工作台创建个人智能体、复制内置模板、选择配置档案提供的企业智能体并开始对话。还可浏览仓库内置技能，并管理团队、自定义技能、MCP 连接器和工作区文件。配置保存在配置档案的 `ui-workbench` Settings 条目中。

<a id="use-this-package"></a>
## 使用本包

助理页分为企业智能体、我的智能体和内置智能体三类。企业定义由配置档案或其管理员提供，在本页只读。内置智能体提供六个模板；从模板创建会生成独立的个人副本。可按名称、描述或 ID 搜索，并切换卡片与表格视图。

智能体编辑页占据应用侧边栏旁的主内容区。步骤栏位于可滚动表单左侧，底部操作栏持续可见。窄窗口会将步骤栏移至表单上方。

通过基本信息、指令、技能、连接器和确认五步创建或编辑个人智能体。可将 ID 留空以自动生成，也可在创建前填写；ID 须在智能体和团队中唯一，编辑时保持不变。名称和指令必填。选择已有技能和连接器、确认配置，并决定保存后是否启用。保存失败时保留草稿；保存成功后返回我的智能体并突出显示已保存的智能体。

个人智能体支持编辑、复制、导出和删除。导出包含其分配的技能和连接器。已启用且预设正常的智能体可以开始对话或设为默认。禁用会将该智能体及包含它的团队移出新会话可选列表，不删除其配置或已有会话。禁用或删除默认智能体、默认团队或其成员前，须先选择其他默认预设。

在专家团中编辑团队指令并选择成员。能力目录提供通过 `/标识` 调用的可编辑 Markdown 技能，以及 HTTP 或本地进程 MCP 连接器。连接器仅在启用且分配给已挂载的专家或团队后启动。本地命令使用独立的 JSON 参数数组；服务凭据使用 Host 环境。

技能页分为内置技能和我的技能。内置技能列出仓库 `.agents/skills/*/SKILL.md` 中的条目，在中文界面显示中文名称和描述；搜索也支持原始技能标识。打开只读详情可查看来源路径，以及元数据是否允许手动或模型调用。我的技能支持新建、编辑和删除自定义技能。

导出 JSON 配置以备份。导入会先验证标识、成员、技能引用和连接器设置，再原子替换四组配置。并发编辑由 Settings 修订号保护。删除专家前须先将其从团队中移除。已有会话保留原预设代际。

资料库使用创作资料面板、文件名搜索和全部、图片、文档、视频、音频、其他分类按钮；数量表示所选会话和当前目录。在资料库中选择会话工作区，即可浏览目录、搜索名称、按文件类型筛选、使用现有文档查看器预览，或在 Host 读取上限内下载完整文件。会话访问和文件系统策略继续生效。删除工作台配置不会删除会话或文件。

<a id="understand-the-implementation"></a>
## 理解实现

Host 通过 `agentPresets` 注册已启用的预设，通过 `skills.registerProvider` 注册技能。团队仅在全部成员已启用时注册。Client 注册四个带键的 `main` 面板和侧边栏入口；注入的控制器使用共享 Settings 表单和工作区文件远程接口。预设更新通过注册表退役旧代际。配置属于配置档案，不使用浏览器存储；缺少归属或启用元数据的定义按个人且已启用处理。

Client 构建时扫描仓库技能的 frontmatter，生成仅包含元数据的目录；带类型的工作台词典负责本地化展示文案。此目录不嵌入技能指令正文。

<a id="model-experience"></a>
## 模型体验

### 专家指令与技能

#### 模型看到什么

所选专家的 `instructions` 和已分配技能的 `content` 进入 persona 前缀。团队包括自身指令、各成员职责和通过 `subagent` 委派工作的指导；调用自定义技能时，技能提供方返回其 Markdown 正文。

#### Token 影响

指令 token 随角色、团队成员和所选技能内容增加。调用技能时增加对应正文的 token。配置导出、内置技能元数据和资料库列表不增加模型输入。

#### KV Cache 影响

会话保留创建时组合的预设代际。编辑专家、团队或所分配技能会改变后续会话的 persona 前缀，可能影响这些会话的前缀复用。调用自定义技能时，技能系统加入其当前内容。

### 工具选择

#### 模型看到什么

专家预设挂载文件系统、Shell、技能、Web、待办、成果展示和子智能体工具。已启用且分配给专家的连接器增加 MCP 服务发现的工具。团队合并各成员的连接器分配。

#### Token 影响

工具 schema 的 token 取决于所组合的预设和已连接服务公布的工具。禁用或未分配的连接器不增加工具。

#### KV Cache 影响

改变连接器分配或启用状态会改变后续预设代际的工具 schema。已有会话保留原组合代际；服务端工具列表的变更遵循 MCP 客户端的刷新行为。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 企业分类表示配置档案提供的定义；本包不提供企业身份或授权服务。智能体启用状态控制新会话的预设可用性，不表示常驻进程的运行状态。
- 显示内置技能不会安装或注册其指令。实际可用性及调用能力取决于各会话工作区的技能发现结果。
- 资料库每次列出一个会话工作区，不索引文件内容。MCP 认证请求头和各服务的环境覆盖在此编辑器之外配置。启用 MCP 连接器不保证服务可达；预设诊断会报告激活失败。
