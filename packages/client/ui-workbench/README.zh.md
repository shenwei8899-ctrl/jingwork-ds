# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

启用原生 Jingwork 登录后，企业智能体通过当前账号的加密设备凭据读取 `/api/agent`。刷新替换远程列表，不将定义写入个人配置。使用企业智能体时，读取当前账号可访问的最新名称、描述和角色提示词，通过带版本校验的 Harness 设置同步企业预设，待其激活后打开原生 Harness 会话。执行采用 Harness 模型和工具。Jingwork 后台的模型、知识库、技能、MCP 和子智能体绑定不属于此次角色同步。

企业列表采用响应式双列卡片，展示授权状态、角色同步信息和原生对话入口；Jingwork 品牌图通过包资源导出随客户端分发。

助理列表以分类标签和紧凑的搜索操作栏开头。

侧栏使用 JingWork 图标，上行显示“竞网蓝鲸”，下行显示“JingWork”。收起侧栏时保留同一图标。展开时品牌组合居中，图标为 40 px，与文字间隔 12 px。

## 概述

通过 Web 或桌面工作台创建个人智能体、复制内置模板、选择配置档案提供的企业智能体并开始对话。还可浏览仓库内置技能，并管理团队、自定义技能、MCP 连接器和工作区文件。配置保存在配置档案的 `ui-workbench` Settings 条目中。

<a id="use-this-package"></a>
## 使用本包

助理页分为企业智能体、我的智能体和内置智能体三类。企业定义由配置档案或其管理员提供，在本页只读。内置智能体提供六个模板；从模板创建会生成独立的个人副本。可按名称、描述或 ID 搜索，并切换卡片与表格视图。

专家模板采用双列卡片，展示统一头像、名称和标识、完整简介、模板标记与添加操作。已添加的模板保留可见状态，窄窗口使用单列。

智能体编辑页占据应用侧边栏旁的主内容区。步骤栏位于可滚动表单左侧，底部操作栏持续可见。窄窗口会将步骤栏移至表单上方。

新建个人智能体分为基本信息、模型配置、知识库、技能、运行工具、子智能体和确认七步。编辑现有智能体时仍可选择连接器。ID 自动生成，在智能体和团队中唯一，编辑时保持不变。名称和指令必填。选择已有技能、确认配置，并决定保存后是否启用。保存失败时保留草稿；保存成功后返回我的智能体并突出显示已保存的智能体。

新建个人智能体默认填写当前界面语言的通用专家名称和日常工作简介，两项均可修改。复制和编辑保留原有内容。

可上传不超过 5 MB 的 PNG、JPEG、WebP 或 GIF 头像，设置聊天首页快捷提问卡片。点击卡片会将其提问内容作为用户消息发送。模型可从目录选择或跟随 Harness 默认值；选定的默认模型记录到新会话，已有会话保留其模型选择。工具分组控制预设中的文件、网页、命令、规划与交互工具，执行遵循部署的沙盒和审批策略。选中的子智能体形成委派工具的预设允许列表。禁用或删除子智能体前须先移除引用。JSON 导出包含引用的子智能体定义及其分配的技能和连接器。

在知识库步骤中选择管理后台配置的一个或多个知识库。目录以紧凑的响应式小卡片展示，选中项会突出显示。原生 Jingwork 登录提供当前账号有权访问的目录，点击刷新可重新获取；目录为空或未登录时显示操作指引。保存的 `knowledgeBases` 标识在编辑、复制及 JSON 导入导出时保留。新会话挂载 `knowledge_search`，仅接受已分配的标识，每次查询由后台检查访问权限。已有的 `knowledge` 参考文本仍受支持。缺少原生后台连接的配置档案无法检索管理的知识库。

`knowledgeRetrieval.timeoutMs` 和 `knowledgeRetrieval.maxBytes` 配置查询限制，默认为 15000 毫秒和 262144 字节。原生凭证管理器通过 `DSH_KNOWLEDGE_URL` 和 `DSH_KNOWLEDGE_TOKEN` 为 Host 提供私有本地检索通道，后台凭证由原生端保管。

助理、专家模板、技能和连接器卡片共用 18px 圆角、16px 内边距及一致的边框和阴影。智能体卡片使用浅蓝至淡紫渐变，鼠标悬停或内部控件获得键盘焦点时切换为更明显的渐变色；头像背景保持透明。个人智能体卡片采用紧凑布局，宽度上限为 380px，操作区在窄窗口中自动换行。个人智能体支持编辑、复制、导出和删除。导出包含其分配的技能和连接器。已启用且预设正常的智能体可以开始对话或设为默认。禁用会将该智能体及包含它的团队移出新会话可选列表，不删除其配置或已有会话。删除当前默认智能体或团队时，先恢复系统默认项。若随后删除失败，智能体保留，并提示重试。禁用默认智能体或默认团队成员前，须先选择其他默认预设。

在专家团中编辑团队指令并选择成员。能力目录将标题和说明置于紧凑的分类与搜索工具栏上方，提供通过 `/标识` 调用的可编辑 Markdown 技能，以及 HTTP 或本地进程 MCP 连接器。连接器仅在启用且分配给已挂载的专家或团队后启动。本地命令使用独立的 JSON 参数数组；服务凭据使用 Host 环境。

技能页分为内置技能和我的技能。卡片在宽屏下显示两列、窄屏下显示单列，包含图标、标题、元数据标记、两行描述和底部操作。完整描述可在详情或自定义技能编辑器中查看。内置技能列出仓库 `.agents/skills/*/SKILL.md` 中的条目，在中文界面显示中文名称和描述；搜索也支持原始技能标识。打开只读详情可查看来源路径，以及元数据是否允许手动或模型调用。我的技能支持新建、编辑和删除自定义技能。智能体编辑器以可选卡片展示全部打包内置技能和已保存技能。可上传带有 `name` 及可选 `description` YAML 元数据的 Markdown 文件，纯 Markdown 文件则以文件名作为标识。指令正文最多 65,536 字符。选中的内置技能和上传技能定义会与智能体在同一次带版本检查的保存中写入配置。取消草稿会丢弃暂存的上传。

连接器页面分为已启用和内置两类，内置腾讯文档、IMA、腾讯会议、腾讯新闻、腾讯乐享、腾讯微云、微信读书、个人邮箱和 QQ 音乐。用户从服务商授权页获取 Token 或 API Key，凭据通过 DSH 本地凭据提供方单独保存，导出配置不包含凭据。将已启用的连接器分配给助理后，新会话才会加载。远程 MCP 服务通过 `mcp-client` 连接。IMA、新闻、微信读书、QQ 音乐和 IMAP/SMTP 由原生适配器执行。网关每次请求读取当前凭据，远程 MCP 在加载新会话时读取凭据。HTTP 或邮箱失败会停止操作，不自动重试。提交失败的修改可能已在远端完成。删除连接器会移除绑定并保留已存凭据，可在凭据设置中清理。

导出 JSON 配置以备份。导入会先验证标识、成员、技能引用和连接器设置，再原子替换四组配置。并发编辑由 Settings 修订号保护。删除专家前须先将其从团队中移除。已在运行的会话保留原预设代际；重启后恢复会话时，使用该预设的当前定义。

资料库列出所有可访问的会话，包括尚未打开的历史会话，并自动打开最近会话的工作目录。刷新会重新读取会话选项和所选目录。所选工作区内的文件按会话分组，归属依据是该会话日志记录的成功修改或显式交付；没有记录归属的文件显示在“未归属资料”下，文件夹继续作为公共导航。旧摘要缺少归属数据时，系统不启动 Agent，直接从该会话日志重建；读取不完整时保留文件并显示提示。使用创作资料面板、文件名搜索和全部、图片、文档、视频、音频、其他分类按钮；数量表示所选工作区和当前目录。图片分类以响应式网格显示保持完整比例的缩略图，并保留文件名、大小、预览和下载操作。点击缩略图打开现有图片查看器；缩略图加载失败时仍可操作文件。面板随文件列表展开，长文件名自动换行，窄窗口将文件操作放在文件名下方。在资料库中选择会话工作区，即可浏览目录、搜索名称、按文件类型筛选、使用现有文档查看器预览，或在 Host 读取上限内下载完整文件。会话访问和文件系统策略继续生效。删除工作台配置不会删除会话或文件。

其他页面宿主可直接渲染无需输入属性的 `workbench.assistants`、`workbench.library` 和 `workbench.knowledge` 组件工厂。`workbench.resources` 工厂接收值为 `experts`、`skills` 或 `connectors` 的 `kind`。这些页面与常规面板共享工作台控制器和配置档案设置。知识库页面按打开编辑器时的 Settings 修订号保存各智能体的参考文本，保存被拒绝时保留草稿。修订号冲突时禁用保存，并提示用户复制草稿、取消并重新打开编辑器。

<a id="understand-the-implementation"></a>
## 理解实现

Host 通过 `agentPresets` 注册已启用的预设，通过 `skills.registerProvider` 注册技能。团队仅在全部成员已启用时注册。工作台为侧边栏和新会话标题提供竞网 logo。Client 注册四个带键的 `main` 面板，以及助理、能力目录和资料库的侧边栏入口；注入的控制器使用共享 Settings 表单和工作区文件远程接口。预设更新通过注册表退役旧代际。配置属于配置档案，不使用浏览器存储；缺少归属或启用元数据的定义按个人且已启用处理。

Client 构建时扫描仓库技能的 frontmatter，生成仅包含元数据的目录；带类型的工作台词典负责本地化展示文案。此目录不嵌入技能指令正文。

<a id="model-experience"></a>
## 模型体验

### 专家指令、技能与知识资料

#### 模型看到什么

所选专家的 `instructions` 和已分配技能的 `content` 进入 persona 前缀。知识资料进入独立的参考资料区段，不进行提示变量插值。团队包括自身指令、各成员职责和知识资料，以及通过 `subagent` 委派工作的指导；调用自定义技能时，技能提供方返回其 Markdown 正文。

#### Token 影响

指令 token 随角色、团队成员、所选技能内容和知识资料增加。调用技能时增加对应正文的 token。配置导出、内置技能元数据和资料库列表不增加模型输入。

#### KV Cache 影响

运行中的会话保留创建时组合的预设代际。编辑专家、团队、所分配技能或知识资料会改变后续会话的系统提示，可能影响这些会话的前缀复用。调用自定义技能时，技能系统加入其当前内容。

### 工具选择

#### 模型看到什么

专家预设挂载文件系统、Shell、技能、Web、待办、成果展示和子智能体工具。已启用且分配给专家的连接器增加 MCP 服务发现的工具。团队合并各成员的连接器分配。

#### Token 影响

工具 schema 的 token 取决于所组合的预设和已连接服务公布的工具。禁用或未分配的连接器不增加工具。

#### KV Cache 影响

改变连接器分配或启用状态会改变后续预设代际的工具 schema。已在运行的会话保留原组合代际；服务端工具列表的变更遵循 MCP 客户端的刷新行为。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 企业分类表示配置档案提供的定义；本包不提供企业身份或授权服务。智能体启用状态控制新会话的预设可用性，不表示常驻进程的运行状态。
- 显示内置技能不会安装或注册其指令。实际可用性及调用能力取决于各会话工作区的技能发现结果。
- 知识库接收参考文本，不上传文件或构建检索索引。
- 资料库每次列出一个会话工作区，不索引文件内容。MCP 认证请求头和各服务的环境覆盖在此编辑器之外配置。启用 MCP 连接器不保证服务可达；预设诊断会报告激活失败。
